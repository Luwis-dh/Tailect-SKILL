# 图片替换与混合素材工作流

适用于新建演示文稿的配图、在现有课件中补图或批量替换图片。若用户或项目指导书规定了实拍/生成比例、人物国别、来源范围或图片数量，优先遵循具体要求。

## 盘点和匹配

- 统计目标页图片框与不同素材数量，分辨正文图、背景、装饰、隐藏对象和重复图片；报告时不混淆图片框数与独立素材数。
- 建立逐框映射：成品页、模板源页、Shape ID/对象名、坐标尺寸、对象/遮罩类型、关联文案、素材和裁切焦点。通过坐标和实际画面核对视觉顺序；ID、对象顺序和文件名都不是阅读顺序。
- 先判断配图在页面上承担的作用：说明人物/动作、提供真实场景、作为隐喻，还是做背景。每幅图必须与相邻内容有明确关系；不得只因颜色相近而选图。
- 用户提供的素材优先。需补图时按“确认可用的实拍—许可清楚的公开摄影—用户允许的 AI 情境图”选择；若用户要求真实照片，不用生成图替代。

## 搜索、真实性与许可

- 优先从有明确许可和来源信息的摄影网站、政府或机构公开媒体库、Wikimedia Commons 等检索。查询时描述具体场景、动作、主体、镜头方向和目标画幅；按需比较多个候选，检查原图分辨率与页面效果。
- 人物主题尽量找真实且职业/场景匹配的摄影作品。涉及中国人物或公检法场景时，优先采用来源能核验为中国拍摄或相关机构场景的照片。不能仅凭外貌推定国籍、身份、职业、单位或事件；无法核实时只作一般情境示意并注明边界。
- 不伪造警徽、警衔、法院或检察院标志、制服细节、案件现场或工作记录。AI 图只能作为情境示意，来源清单需明确标记，不冒充真实人物、地点、机构或事件。
- 许可不清或不允许目标用途的素材不采用。逐项记录：作品名、摄影者、来源页面、原图链接（可取得时）、许可名称及链接、获取日期、要求的署名、使用页码/对象、裁切版本路径。保存必要的许可或作者证据，方便复核。
- 检查画面质量、焦点、光线、分辨率、是否摆拍、重复使用和人物构图；来源照片的说明不一定能证明所有人物身份。不可将通用图库人物认定为特定职业或国籍。

## 比例、裁切与替换

- **禁止非等比拉伸。**先记录目标框宽高和原图比例，按目标框比例裁切或在 PowerPoint 中调整裁切焦点，保持图片宽高比例。主体不适合目标框时换图或调整框的构图，不能压缩或拉长图片迁就版式。
- 逐图检查脸部、手部、制服/标志、动作、背景地标和画面边缘；确认主要主体未被切掉、未被文字或形状挡住。必要时保留原图并另存裁切副本，记录裁切焦点。
- 优先通过 PowerPoint“更改图片”或等效原位操作保持形状、遮罩、位置、尺寸、旋转、层级、动画和可编辑性。图片填充、组合图、背景和特殊透视对象需先识别对象类型再处理。
- 大批量替换仅在映射核准后操作。若使用 OOXML 媒体关系，避免重建幻灯片形状树或改动无关主题、文本、动画；替换后在 PowerPoint 重新打开和实际渲染检查。
- 尽量避免相邻页或同一组卡片重复使用同一照片。素材受限时可用真实地点、器材或中性特写补足，不要为凑数量塞入主题不符的图片。

## 复核与交付

- 替换后导出最终 PPTX 的整套页面预览；逐页核对图片与文案、主体位置、裁切、清晰度、人物/场景真实性、重复素材、文字遮挡和风格一致。重点页打开全尺寸检查。
- 复核 PowerPoint 中对象填充、图片关系和动画引用是否保持。若有动画且指导书要求播放验证，必须在放映模式中实际查看；未播放的页面明确写“待验证”。静态图和 XML 不代表动画已通过。
- 交付可编辑 PPTX；默认附全页预览、逐图来源与许可清单、复核摘要。说明目标图片框数、独立来源数、实拍与 AI 图片数量、无法核实的身份/地点，以及未完成的检查。
