# PowerPoint 原页编辑与核验

1. 打开模板和独立工作文稿。每页先确认源页和对象结构；不保存对原模板的修改。将原页复制到工作文稿，选择“保留源格式”，不要贴成图片；确认色彩、字体和比例。
2. 在原文本框内替换示例文字。尽可能保留对象、文本层级和原有格式；检查空白、溢出、行距、数字与单位。删除不适用的示例对象前先检查动画绑定。
3. 普通图片优先选原图右键“更改图片”，使用用户图片或合适的高质量图片，检查裁切和主体位置。组合内图片、图形填充、背景、特殊透视图可能不是普通图片：识别对象后使用 PowerPoint 合适操作，勿声称所有对象都支持相同替换方式。真实人物、地点、事件不能用生成图冒充。
4. 编辑涉及组合或动画对象时尽量保留原对象。检查动画窗格的目标、顺序、触发、时长与原页相应设置；在 PowerPoint 中实际放映查看。更改图片通常可能保留原对象，但不保证所有效果，必须逐页验证。
5. 用放映及编辑视图检查可读性、构图、图片裁切、字体替代、示例信息残留和动画；PPTX 保持可编辑。单独指出动画丢失、无法验证或待补充内容。不可把 PPTX 的动画标记、PDF 或静态缩略图当成播放验证。

已观察：将第 40 页复制到新文稿后缩略图显示有动画；直接默认粘贴可能使用目标主题，需要选保留源格式。该观察不证明图片替换后动画已通过测试。当前模板没有内嵌字体，换机器时需检查字体替代。
