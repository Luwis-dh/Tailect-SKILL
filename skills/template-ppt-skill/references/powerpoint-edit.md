# PowerPoint 制作、编辑与核验

主 Skill 负责判断内容、版式和交付；本文件说明 PowerPoint 操作与验收。始终遵循当前项目指导书指定的接口、保留事项和输出路径。

## 新建或套用模板

1. 确认模板文件版本和比例；原模板只读。先在目录/索引中搜候选页，再在 PowerPoint 中查看源页的真实构图、对象、遮罩和动画。
2. 在独立工作文稿中复制所需原页并选“保留源格式”。保留母版和可编辑对象；不将整页截图贴回 PPT。没有合适原页时，使用适配的组合或有限局部调整，并维持整套模板的视觉连贯。
3. 替换示例文本前确认事实来源；保留层级与必要格式，核对标点、数字单位、换行、段距、溢出和动画绑定。删除对象前检查其动画及其他引用。

## 编辑现有课件

1. 先复制到工作目录，确认源文件页数、比例、字体、对象层级、背景和动画；不覆盖用户原件，除非用户明确要求原位修改。
2. 逐页映射编辑对象和内容。可直接编辑原文本框；图片优先使用“更改图片”或同等原位操作。组合、图形填充、背景、特殊遮罩等先辨别对象类型，不能假定普通图片替换对所有形状适用。
3. 不要仅凭对象顺序、Shape ID 或文件序号判断画面顺序。结合坐标、相邻文字和 PowerPoint 渲染核准对应关系。
4. 保留用户未要求修改的对象、主题、动画、转场、备注和可编辑文字。确需改动时，记录原因和影响，并核验修改后的输出。

## 渲染与检查

- 使用 PowerPoint 对象接口或指导书指定的文档接口保存、重新打开并导出预览；检查完整 deck 的总览和需要重点审查的全尺寸页面。静态预览只能检查静态视觉，不能证明动画播放正确。
- 页面复核：文字准确且无溢出；标题和正文层级清楚；字体替代合理；图片与文案匹配且主体未被裁掉；图片无非等比拉伸；无不必要的遮挡、贴边、孤字或对象错位；颜色对比和阅读路径明确。
- 文件复核：PPTX 可重新打开；页数、页面比例、图片对象、媒体关系、主要可编辑对象、备注及源文件要求的动画/转场保持预期。
- 对有动画的页面，按指导书在 PowerPoint 放映中实际检查对象目标、触发、顺序、延迟、时长和效果。只检查确实播放过的页面；其他页面在记录中标注“动画待验证”。
- 发现问题就修正并重新导出对应页面；交付预览必须与最终保存的 PPTX 同一版本。不得将 OOXML/XML 检查、PDF、第三方转换器或静态缩略图称为 PowerPoint 动画验收。

## 受阻处理与记录

- 若指导书要求的 PowerPoint 接口不可用，保存隔离工作副本，说明错误、最后完成页和未完成项。继续可独立完成的内容整理、图片检索、许可核验和对象映射；不伪称页面或动画已通过验收。
- 每页记录至少包含：成品页及主题、模板源页（如有）、页面目标、主要修改、对象/图片对应、渲染预览路径、内容与视觉检查、动画检查状态、待补事项。
- 字体未嵌入时，检查交付环境中的替代效果；明确说明可能影响换行或版式的风险。
