## 索引字段和局限

`catalog/slides.json` 中包含每页的分区、提取的版式标签、由标签推断的关键词、页面示例文字、图片/形状/组合对象数、是否存在动画结构以及缩略图路径。原文、标签及对象数均来自 OOXML 自动提取，未逐页视觉人工核实。图片对象数包含装饰和其他图片，不能直接视为需要替换的图片数量；文字提取不能反映位置、字号、裁切、可读性和层次。`has_timing` 只表明存在动画数据，并不证明其内容、目标或播放效果。模板中的姓名、数字和项目文字均为示例，不可视为事实。

`catalog/thumbnails/slide-NNN.jpg` 来自改名前模板的静态预览；与当前文件逐页提取的文字一致，但尚未逐页比较图片和布局，可能与当前版本有差异，主要用来粗看版式；转换器对部分字体和效果支持不完整，可能出现文字缺失、字体替换、动画末帧或其他差异。最终必须在 PowerPoint 实看源页。缩略图不能验证动画。若对应预览缺失，以 PowerPoint 视图为准。

## 使用检索

从技能目录运行，例如：

```bash
python3 scripts/search_slides.py --items 4 --section 图文 --limit 12
python3 scripts/search_slides.py 人物 --section 人物 --limit 12
python3 scripts/search_slides.py 证书 --animation yes --limit 10
python3 scripts/search_slides.py --pages 431-458 --limit 28
python3 scripts/search_slides.py 4图 并列 --limit 20
```

关键词是精确子串的宽松 OR 检索而非语义搜索。`--items` 仅筛选标签中自动识别的数量，可能漏检或误判，不能当作完整结果。应尝试数字与中文两种写法（如 `4图`、`四图`、`4张图片`）、不同用途词和版式词，查看多个候选。搜索结果只代表原始文字匹配；根据素材的信息关系、项目数、图片条件和文字密度目视比较，必要时翻看邻近页和变体。不能因为示例主题相同就忽视版式匹配。

先对源文件运行 `shasum -a 256`，与 JSON 的 `sha256` 比较。若不一致，页码和缩略图可能失效：在 PowerPoint 核对，重新索引并更新分区和预览，不能静默使用旧索引。构建脚本目前的分区边界针对该版本写定，重建不同版本前必须根据 PowerPoint 实际分区修订脚本。重新提取不等于完成逐页视觉检查。
