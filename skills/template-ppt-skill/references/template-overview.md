# 青绿色 606 页模板目录与检索

本索引只适用于随 Skill 提供的这一版 606 页青绿色 PowerPoint 模板。用户提供其他模板或现有课件时，以用户文件为准；不得把本目录的页码、预览、分区或示例套用到其他文件。模板原件约 260 MB，不随 Skill 分发。

## 定位与版本确认

模板路径使用环境变量 `TEMPLATE_PPTX` 或用户明确提供的路径；未设置时，先检查 Skill 所在目录的上级目录是否有 `ppt模版.pptx`。新建演示文稿且需要此模板、但找不到模板时，继续处理可独立完成的内容分析与逐页规划，并在制作前说明缺少模板文件。

先核对源文件 SHA-256 与 `catalog/slides.json` 中的 `sha256`。文件移动或改名不影响核对；版本哈希不一致时，旧页码和缩略图不得作为事实依据。应在 PowerPoint 检查实际文件，必要时重新生成索引、缩略图和分区信息，再继续选页。不要猜页码，也不要修改原模板。

## 索引的用途与局限

`catalog/slides.json` 记录自动提取的版式标签、关键词、示例文字、对象数量、动画结构和缩略图路径。提取结果只用于缩小搜索范围：图片数包含装饰对象；文字提取看不出字体、字号、层级和阅读顺序；`has_timing` 只表示文件里有动画数据，不能证明动画目标或效果。

`catalog/thumbnails/slide-NNN.jpg` 是静态参考图，不验证动画。转换可能丢失字体或效果，也可能与模板现版本的图片/版式不一致。源页最终选择、对象映射和裁切判断都须按项目要求在 PowerPoint 中查看。

## 搜索方法

在 Skill 目录运行检索脚本：

```bash
python3 scripts/search_slides.py --items 4 --section 图文 --limit 12
python3 scripts/search_slides.py 人物 --section 人物 --limit 12
python3 scripts/search_slides.py 证书 --animation yes --limit 10
python3 scripts/search_slides.py --pages 431-458 --limit 28
python3 scripts/search_slides.py 4图 并列 --limit 20
```

搜索是基于文本的宽松 OR 检索，不是语义理解。尝试中英文、数字与中文数量词（如 `4图`、`四图`、`4张图片`）、页面用途和版式词；检查多个候选和邻近变体。再根据素材的信息关系、图片数量、文字密度及实际画面挑选，不因示例内容看起来相似就直接套用。

模板里的姓名、数字、案例和图片均是示例，不可当作本次事实。选择后记录成品页、源页、匹配原因和需替换对象；复制时保留源格式。最终以 PowerPoint 中实际打开的源页和成品为准。
